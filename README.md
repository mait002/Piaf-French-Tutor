# Piaf

Piaf is a French-learning conversational chatbot powered by the **Qwen3:4B-Instruct** model.

The chatbot adapts its conversations based on the user's selected **CEFR French proficiency level** and provides personalized feedback throughout the conversation.

## Features

- Conversational French practice
- CEFR-based difficulty levels
- Personalized grammar and language corrections
- Explanations for mistakes
- Adaptive conversations that focus on areas where the user needs more practice
- French text-to-speech support for listening and pronunciation practice

## How It Works

Users select their French proficiency level and begin chatting with Piaf in French. Piaf adjusts its responses to match the selected level, identifies mistakes, provides corrections, and uses the user's recurring difficulties to guide future conversation topics and practice.

## Tech Stack

- **Next.js**
- **TypeScript**
- **Tailwind CSS**
- **Qwen3:4B-Instruct**
- **Ollama**
- **Web Speech API**
